# Interconnect the solar array

## When to use

On any job with a photovoltaic array, alongside the permit step. The array can be installed long before it is allowed to export.

## Inputs

- The survey's unshaded area, azimuth, tilt and structural notes
- The electrical service details: panel rating, main breaker, available busbar capacity
- The utility's interconnection rules and the authority's electrical permit requirements

## Steps

1. Size the array to the roof and the service: module count and layout per plane, inverter selection, string design, and whether the busbar can carry the backfeed.
2. Model expected production for the site: orientation, tilt, shading and soiling. Say which tool and assumptions you used; the number will be compared to reality later.
3. Check the structure: dead and live load with the array, attachment method and spacing, and whether a stamped engineering letter is required.
4. File the utility interconnection application with the one-line diagram, equipment data sheets and the site plan. Record the application number and the date.
5. File the electrical permit with the authority, which is often a separate application from the roofing permit.
6. Track both reviews. Answer utility and plan-check questions quickly; interconnection queues move slowly and silently.
7. On approval to install, build it as designed. Document any field deviation, because the as-built has to match what gets inspected.
8. Commission the system: inverter settings, string voltages and currents, labelling, rapid shutdown, monitoring online.
9. Book the electrical inspection, then submit for permission to operate. Record the date it is granted; before it, the system must not export.
10. Hand over: monitoring access, what normal production looks like, and who to call.

## Outputs

- Array design, production model and structural check
- Interconnection application, approval and permission to operate, with dates
- Commissioning record and monitoring handed over

## Checks

- Don't energise or export before permission to operate.
- Keep the as-built matched to the approved design, or the inspection will find the difference.
- Record the production model; the first year's monitoring is measured against it.

## Notes

Interconnection rules, timelines, incentive paperwork and net metering terms differ by utility and state and change often. Confirm the current requirements with the utility before promising a date.
