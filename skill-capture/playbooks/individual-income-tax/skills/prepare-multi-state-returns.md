# Prepare multi-state returns

## When to use

Branch after "Prepare the return" when the client moved or earned income in another state (including remote work and K-1s with state-source income).

## Inputs

- Move dates, W-2 state wage boxes, K-1 state schedules, rental property locations

## Steps

1. Establish residency for each state and the dates (domicile, days present, move date).
2. Allocate wages by work location and other income by source, following each state's rules.
3. Prepare nonresident returns first, then the resident return with a credit for tax paid to the other states.
4. Check local income taxes where the client lived or worked.
5. Rejoin the mainline.

## Outputs

- Each required state return with an allocation schedule

## Checks

- Income isn't taxed twice without a credit, or left untaxed.
- State withholding is claimed on the right return.
