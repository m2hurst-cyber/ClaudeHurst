# Organize the financial information

## When to use

When the document checklist is complete (or the missing items are known).

## Inputs

- Source documents and the organizer workbook
- Last year's return for comparison

## Steps

1. Enter each document in the organizer's workpaper tab, one row per form, with the payer and the box amounts you'll use.
2. Tie each total back to the document (withholding, interest, dividends, distributions) and initial it.
3. Compare every line to last year. Anything that moved more than 10%, or appeared or disappeared, gets a one-line explanation from the documents or the client.
4. List open questions for the client in one place and send them together.
5. Record carryovers from last year where they'll be used.

## Outputs

- Tied-out workpapers, a prior-year comparison with explanations, and one list of client questions

## Checks

- No figure enters the return without a source document or a written client representation.
- Personal identifiers stay in the tax software and the secure folder, not in shared workbooks.
