# Review the return

## When to use

Every return, before e-filing. The reviewer is not the preparer.

## Inputs

- The draft return, workpapers, prior-year return and the return review checklist (resource)

## Steps

1. Work through the review checklist: identity details, filing status, dependents, every income document present, carryovers, deductions and credits supported, state returns consistent.
2. Send review notes to the preparer; clear them all before the client sees the return.
3. Walk the client through the return: income, deductions, credits, balance due or refund, payment or deposit details.
4. Send Form 8879 (and the state equivalent) for electronic signature, with the amounts it states.
5. Keep the signed 8879 with the return; don't transmit without it.

## Outputs

- A reviewed return with cleared notes and a signed Form 8879

## Checks

- The 8879 amounts equal the final return; if anything changed after signing, get it re-signed.
- The client confirmed the bank account used for refunds or debits.
