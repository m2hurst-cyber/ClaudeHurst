# File an extension (Form 4868)

## When to use

Branch at "E-file the return" when the return can't be filed by the original deadline.

## Inputs

- The best available income and payment figures, and what's still missing

## Steps

1. Estimate total tax from what's known, last year's return and the missing items.
2. Compare to withholding and estimates paid; the difference is the amount to pay now.
3. File Form 4868 (or make an extension payment that counts as one) and each state's extension by the original due date.
4. Pay the estimated balance (see "Pay the tax") and record the confirmation.
5. Tell the client the new filing date (generally October 15) and what's still needed.
6. Return to the mainline when the documents arrive.

## Outputs

- Accepted extensions and a paid estimate, with a dated list of what's outstanding

## Checks

- The estimate is reasonable and documented; an unreasonable estimate can void the extension.
- The extended deadline is diarised.
