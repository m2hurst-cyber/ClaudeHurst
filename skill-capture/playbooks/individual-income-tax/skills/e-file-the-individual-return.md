# E-file the return

## When to use

After review, with the signed 8879, by the filing deadline (generally April 15; October 15 on extension).

## Inputs

- The reviewed return and the signed Form 8879

## Steps

1. Transmit the federal and state returns.
2. Check acknowledgments within 48 hours. An accepted federal return gets its acceptance date recorded.
3. For a rejection, read the reject code, fix the cause (often an identity mismatch or a dependent claimed elsewhere), and retransmit; tell the client if the cause is on their side.
4. If the return can't be filed electronically, mail it by certified mail and keep the receipt.

## Outputs

- Accepted federal and state returns with acknowledgment records

## Checks

- Every return transmitted has an "accepted" acknowledgment on file.
- A rejected return is fixed and retransmitted within the IRS's perfection period.
